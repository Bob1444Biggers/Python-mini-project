# Утилита обработки банковских данных (Bank Data Processing Utility)

Проект представляет собой библиотеку утилит на Python для бэкенд-обработки, фильтрации, агрегации и маскирования данных по банковским транзакциям. Он оптимизирован для работы с большими объемами данных с использованием потоковых генераторов и включает развитую систему логирования.

## Основной функционал

* **Маскирование данных (`masks.py`, `widget.py`):** Безопасное скрытие номеров карт (в формате `XXXX XX** **** XXXX`) и счетов (`**XXXX`) для защиты персональных данных.
* **Фильтрация и сортировка (`processing.py`):** Фильтрация транзакций по их статусу (например, `EXECUTED`), сортировка по хронологии и подсчет статистики операций по категориям.
* **Потоковая обработка (`generators.py`):** Экономичные по памяти генераторы для ленивой фильтрации транзакций по валютам и динамической генерации тестовых номеров карт.
* **Логирование (`logs/`):** Автоматическое ведение отладочных журналов работы модулей маскирования в файлы конфигурации.

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   ```
2. Установите зависимости через Poetry:
   ```bash
   poetry install
   ```

## Использование модулей

### Модуль processing

Позволяет фильтровать и сортировать списки транзакций:

```python
from src.processing import filter_by_state, sort_by_date

data = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 59422672, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}
]

# Фильтрация успешных операций
executed_data = filter_by_state(data)

# Сортировка по дате
sorted_data = sort_by_date(data)
```

### Модуль generators

Позволяет эффективно обрабатывать транзакции по одной (через генераторы):

```python
from src.generators import filter_by_currency

# Ленивая фильтрация потока транзакций по USD
usd_transactions = filter_by_currency(transactions_stream, "USD")
```

## Тестирование

В проекте используется библиотека `pytest` для автоматического тестирования модулей. Написаны параметризованные тесты и фикстуры, обеспечивающие покрытие кода более чем на 80%.

### Запуск тестов

Для запуска всех тестов выполните в терминале команду:

```bash
pytest
```

### Анализ покрытия кода (Coverage)

Для генерации HTML-отчета о покрытии кода тестами выполните:

```bash
pytest --cov=src --cov-report=html
```

После выполнения команды подробный отчет будет доступен в локальной папке `htmlcov/index.html`.
